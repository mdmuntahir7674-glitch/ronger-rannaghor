# রঙের রান্নাঘর (Ronger Rannaghor)

React + Vite project. Site code is unchanged from the original single-file version
(`public/legacy/app.js`, `src/styles.css`, `src/markup.html`); images are in `public/assets/img`.

    npm install
    npm run dev       # local
    npm run build     # outputs dist/

Deploy: push to GitHub, import the repo on Vercel (Framework: Vite, build `npm run build`, output `dist`).
